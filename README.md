# 年金に係る雑所得の計算方法（エクセル自動計算ツール）

公的年金等および公的年金等以外の年金について、年間収入金額などを入力することで、雑所得の金額を自動計算できるExcel（エクセル）ファイルです。

本Excelファイルには、以下の2つの計算シートを収録しています。

- 「公的年金等に係る雑所得」
  公的年金等の年間収入金額から、公的年金等に係る雑所得を計算します。

- 「公的年金等以外の年金に係る雑所得」
  公的年金等以外の年金（個人年金など）に係る雑所得を計算します。

公的年金等については、国税庁が公開している「公的年金等に係る雑所得の速算表」を参考に作成しています。

ねんきん定期便などに記載された将来の年金収入見込額や、個人年金などの収入金額を利用することで、年金に係る雑所得のおおよその金額を把握し、確定申告や税金対策の準備・計画を立てる際の参考としてご利用いただけます。

## 概要

年金に係る雑所得は、年金の種類によって計算方法が異なります。

本Excelファイルでは、以下の2種類の年金について、それぞれの計算方法に対応しています。

### 1. 公的年金等に係る雑所得

公的年金等に係る雑所得は、公的年金等の収入金額から公的年金等控除額を差し引いて計算します。

「公的年金等に係る雑所得」シートでは、年齢区分と公的年金等の年間収入金額を入力することで、速算表に基づいて雑所得の金額を自動的に算出します。


### 2. 公的年金等以外の年金に係る雑所得

公的年金等以外の年金（個人年金など）に係る雑所得は、年金の収入金額から、その年金に対応する必要経費を差し引いて計算します。

「公的年金等以外の年金に係る雑所得」シートでは、年金の収入金額や必要経費などを入力することで、公的年金等以外の年金に係る雑所得を計算できます。


## 対応内容

- 公的年金等の計算：「公的年金等に係る雑所得」シートで計算
- 公的年金等以外の年金の計算：「公的年金等以外の年金に係る雑所得」シートで計算
- 年齢区分対応：公的年金等について65歳未満・65歳以上の年齢区分に対応
- 簡単入力：必要な金額を入力するだけで計算できるシンプルな設計
- 自動計算：入力値に応じて雑所得の金額を自動計算
- ロジックの透明性：計算に使用する判定表や計算式などをシート内で確認可能


## 使い方・シミュレーション手順

### 公的年金等に係る雑所得を計算する場合

1. ダウンロードしたExcelファイルを開きます。
2. 「公的年金等に係る雑所得」シートを開きます。
3. 年齢区分（65歳未満・65歳以上）を選択します。
4. 公的年金等の年間収入金額（額面）を入力します。
5. 公的年金等に係る雑所得の計算結果を確認します。


### 公的年金等以外の年金に係る雑所得を計算する場合

1. 「公的年金等以外の年金に係る雑所得」シートを開きます。
2. 年金の収入金額など、必要な項目を入力します。
3. 必要経費などの金額を入力します。
4. 公的年金等以外の年金に係る雑所得の計算結果を確認します。


## 計算方法・ロジック

### 公的年金等に係る雑所得

公的年金等に係る雑所得は、年齢区分と公的年金等の収入金額に応じて、国税庁が定める計算方法・速算表を使用します。

基本的な計算の考え方は次のとおりです。

公的年金等に係る雑所得
= 公的年金等の収入金額 - 公的年金等控除額

実際の計算では、収入金額の区分に応じた割合（乗数）や控除額が適用されます。


### 公的年金等以外の年金に係る雑所得

公的年金等以外の年金に係る雑所得は、基本的に以下の考え方で計算します。

公的年金等以外の年金に係る雑所得
= 年金の収入金額 - 必要経費

個人年金などの場合、必要経費の計算方法は年金の契約内容などによって異なる場合があります。

そのため、実際の確定申告などで利用する場合は、契約書や支払通知書などの内容を確認し、必要経費の金額が適切であることをご確認ください。

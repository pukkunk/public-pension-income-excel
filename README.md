# 年金等に係る雑所得の計算方法（エクセル自動計算ツール）

公的年金等の年間収入金額から、公的年金等に係る雑所得の金額を自動計算できるExcel（エクセル）ファイルです。

国税庁が公開している「公的年金等に係る雑所得の速算表」を参考に作成しており、年齢区分と公的年金等の収入金額を入力するだけで、雑所得の金額を簡単にシミュレーション・試算できます。

ねんきん定期便に記載された将来の年金収入見込額などを利用することで、老後の公的年金等に係る雑所得のおおよその金額を把握し、確定申告や税金対策の準備・計画を立てるためにもご活用いただけます。

## 概要

公的年金等に係る雑所得は、公的年金等の収入金額から公的年金等控除額を差し引いて計算します。

本Excelテンプレートでは、年齢区分を選択し、公的年金等の年間収入金額を入力することで、対応する計算式（税法区分）に基づいて雑所得の金額を自動的に算出します。

## 対応内容

* **年齢区分対応**: 65歳未満・65歳以上の年齢区分に完全対応
* **簡単入力**: 公的年金等の年間収入金額を入力するだけのシンプルな設計
* **自動判定**: VLOOKUP関数を利用した正確な速算表の区分判定
* **雑所得計算**: 公的年金等に係る雑所得の金額を自動計算
* **ロジックの透明性**: 計算に使用する判定表や計算式（控除額・割合）をシート内で直接確認可能

## 使い方・シミュレーション手順

1. ダウンロードしたExcelファイルを開きます。
2. 年齢区分（65歳未満・65歳以上）をドロップダウン等から選択します。
3. 公的年金等の年間収入金額（額面）を入力します。
4. 画面上で公的年金等に係る雑所得の計算結果を確認します。

## 計算方法・ロジック

公的年金等に係る雑所得は、年齢区分と公的年金等の収入金額に応じて、国税庁が定める以下の計算式・速算表を使用します。

基本的な計算の考え方は次のとおりです。

```text
公的年金等に係る雑所得 = 公的年金等の収入金額 - 公的年金等控除額
```

実際の計算では、収入金額の区分に応じた割合（乗数）や控除額が自動的に適用されます。

## 注意事項

* 本Excelファイルは、公的年金等に係る雑所得の試算・計算を補助するための無料ツールです。
* 計算結果は税務上の最終的な判断を保証するものではありません。
* 実際の確定申告や厳密な税額計算を行う際は、必ず最新の法令および国税庁の公式資料をご確認ください。
* 公的年金等以外の所得（給与所得やその他の雑所得）、各種所得控除（配偶者控除・医療費控除など）、税額控除などは、別途考慮する必要があります。
* Excelの計算結果を参考にする際は、入力値やシート内の計算式が適切であることをユーザーご自身でもご確認ください。

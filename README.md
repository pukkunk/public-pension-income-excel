# 年金等に係る雑所得の計算方法

公的年金等の年間収入金額から、公的年金等に係る雑所得の金額を計算するExcelファイルです。

国税庁が公開している「公的年金等に係る雑所得の速算表」を参考に、年齢区分と公的年金等の収入金額を入力して、雑所得の金額を計算できます。

ねんきん定期便に記載された年金収入の見込額などを利用することで、将来の公的年金等に係る雑所得のおおよその金額を把握するためにも使用できます。

## 概要

公的年金等に係る雑所得は、公的年金等の収入金額から公的年金等控除額を差し引いて計算します。

本Excelでは、年齢区分を選択し、公的年金等の年間収入金額を入力することで、対応する計算式に基づいて雑所得の金額を算出します。

## 対応内容

* 65歳未満・65歳以上の年齢区分に対応
* 公的年金等の年間収入金額を入力
* VLOOKUP関数を利用した区分判定
* 公的年金等に係る雑所得の計算
* 計算に使用する判定表・計算式を確認可能

## 使い方

1. Excelファイルを開きます。
2. 年齢区分（65歳未満・65歳以上）を選択します。
3. 公的年金等の年間収入金額を入力します。
4. 公的年金等に係る雑所得の計算結果を確認します。

## 計算方法

公的年金等に係る雑所得は、年齢区分と公的年金等の収入金額に応じて、国税庁が定める計算式を使用します。

基本的な考え方は次のとおりです。

```text
公的年金等に係る雑所得
= 公的年金等の収入金額
  - 公的年金等控除額
```

実際の計算では、収入金額の区分に応じた割合や控除額を使用します。

## 注意事項

* 本Excelは、公的年金等に係る雑所得の計算を補助するためのものです。
* 計算結果が税務上の最終的な判断を保証するものではありません。
* 実際の確定申告や税額計算では、最新の法令・国税庁の資料をご確認ください。
* 公的年金等以外の所得、所得控除、税額控除などは、別途考慮が必要です。
* Excelの計算結果を利用する際は、入力値や計算式が適切であることを確認してください。
